# it-dkt.github.io

🎮 **Play here: https://it-dkt.github.io/**

The games here were made with [avg.NET](https://github.com/it-dkt/avg.NET), an adventure game framework, and converted to run on HTML and JavaScript alone.
No server is needed. You can play them right in your browser. (But the language is Japanese only, sorry)

The games (scenarios, images and music) were created by AI (Claude), which also converted them to HTML / JavaScript.
ChatGPT was also used to generate images.
